# Flow fictional demo

[Open the demo](https://goddyjay.github.io/flow-fictional-demo/)

This is an interactive sample for early usability feedback. It uses only invented USD amounts dated October 6, 2026. Visitors can explore Home, Money Map, Forecast, and Can I afford it?, then copy feedback to send to the person who shared the link.

Choices and typed feedback stay on the visitor's device. The site has no sign-in, bank connection, analytics, database, or feedback submission endpoint. Refresh or use **Reset demo** to clear the sample state. Please do not enter real financial information.

The demo shows a limited, fixed scenario. It is not the full Flow application or a real-finance beta.
